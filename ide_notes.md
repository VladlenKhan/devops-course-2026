# VS Code и Git

## Что удобно в VS Code

1. **Визуальный просмотр изменений** — удобно видеть, какие строки были добавлены, изменены или удалены перед коммитом.

2. **Удобная работа с коммитами** — можно быстро добавить изменённые файлы в commit и создать коммит прямо из интерфейса VS Code.

3. **Просмотр истории Git** — удобно видеть список коммитов и понимать, какие изменения происходили в проекте.

## Что удобнее делать в терминале

**Работа с удалёнными репозиториями и сложными Git-командами** удобнее в терминале. Например, можно быстро выполнить `git push`, `git pull`, `git branch` или настроить remote.
